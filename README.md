# Little Lemon App

A React app for the Little Lemon restaurant. You can set up and run the project
from Windows PowerShell without an IDE.

## Requirements

Install [Node.js](https://nodejs.org/) (the LTS version is recommended). npm is
included with Node.js.

Check the installation:

```
node --version
npm --version
```

## Setup

Open PowerShell and move to the project folder:

```
cd C:\path\to\little-lemon-app
```

Install the dependencies:

```
npm install
```

## Run

Start the development server:

```
npm start
```

The app should open automatically. If it does not, visit
[http://localhost:3000](http://localhost:3000).

Press `Ctrl+C` in PowerShell to stop the server.

No backend, database, API key, or `.env` file is required.

## Other commands

Run the tests:

```
npm test
```

Create a production build in the `build` folder:

```
npm run build
```
